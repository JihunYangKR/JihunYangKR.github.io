# Personal Portfolio & Knowledge Archive

개인 포트폴리오와 장기 지식 아카이브를 구축하는 프로젝트입니다.

## 프로젝트 개요

GitHub Pages와 Jekyll을 이용하여 개인 포트폴리오와 장기 지식 아카이브를 구축하고 있습니다.

## 주요 기능

- 반응형 포트폴리오
- Markdown 기반 아카이브
- Categories
- Tags
- Search
- Year Archive
- Dark Mode
- MathJax
- SEO

## 사용 기술

- HTML
- CSS
- JavaScript
- Jekyll
- GitHub Pages

## 현재 상태

개발 중이며 지속적으로 기능을 추가하고 있습니다.
