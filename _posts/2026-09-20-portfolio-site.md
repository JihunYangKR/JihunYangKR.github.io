# Personal Portfolio & Knowledge Archive

개인 포트폴리오와 장기 지식 아카이브를 구축하는 프로젝트입니다.

## 1. 프로젝트 개요

GitHub Pages와 Jekyll을 이용하여 개인 포트폴리오와 지식 아카이브를 하나의 사이트로 통합했습니다.

## 2. 프로젝트 목적

- 개인 프로젝트 기록
- 공부 및 연구 기록
- 자료 장기 보존
- 포트폴리오 공개

## 3. 주요 기능

- Markdown 기반 글 작성
- Categories
- Tags
- Search
- Year Archive
- Dark Mode
- MathJax
- Responsive Design

## 4. 사용 기술

- HTML
- CSS
- JavaScript
- Jekyll
- GitHub Pages

## 5. 결과

현재 개발 중이며 지속적으로 기능과 콘텐츠를 추가할 예정입니다.
