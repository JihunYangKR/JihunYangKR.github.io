# Personal Portfolio & Knowledge Archive

개인 포트폴리오와 장기 지식 아카이브를 구축하고 관리하는 Profile입니다.

GitHub Pages와 Jekyll을 기반으로
개인 작업과 지식을 장기적으로 기록하고 관리할 수 있는
웹사이트를 만들어가고 있습니다.

## 주요 기능

- 반응형 포트폴리오
- Markdown 기반 Archive
- Categories
- Tags
- Search
- Year Archive
- Dark Mode
- MathJax
- SEO

## 사용 기술

- HTML
- CSS
- JavaScript
- Jekyll
- GitHub Pages

## 현재 상태

지속적으로 기능을 개선하고 실제 콘텐츠를 추가하고 있습니다.
